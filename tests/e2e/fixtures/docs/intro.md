# Introduction

The E2E API lets you manage pets, orders and your own account.

## Before you start

Create an environment, set your token, and you are ready to send requests.
Start with [create a pet](apidoc:createPet), then [list them](apidoc:GET /pets).
A reference nobody can resolve stays [visibly broken](apidoc:ghostOperation).

## What is covered

```apidoc:operation
GET /pets
createPet
getPet
GET /nowhere
```
